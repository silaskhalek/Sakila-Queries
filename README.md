# Sakila-Queries 💾
Queries gerais de MySQL para banco de dados Saklia

# Práticas com Queries SQL no Banco de Dados Sakila ✍🏼
Este repositório contém exemplos de consultas SQL no banco de dados Sakila, que simula um sistema de locação de DVDs. As queries variam desde consultas básicas até consultas mais complexas, utilizando joins, agregações e subconsultas.

# Sobre o Banco de Dados Sakila 🖥️
O banco de dados Sakila é um banco de dados de exemplo amplamente utilizado para praticar SQL. Ele contém tabelas como actor, film, customer, rental, payment, entre outras, que simulam um sistema de locação de DVDs.
